# SDF Converter

CLI tool that extracts every table and column from SQL Server Compact Edition (`.sdf`) files and writes `.sql` files for a chosen target dialect.

## Why?

SQL Server CE libraries only exist for .NET Framework, so this is Windows-only. No viable Rust, Node.js, or Python alternative reads `.sdf` files.

## Workflow

```
.sdf  -->  SdfConverter.exe  -->  {sdfname}.sql  -->  target database
```

## Features

- Exports all tables and all columns as-is (dynamic schema)
- Target dialects: SQLite (default), PostgreSQL, SQL Server, MySQL, MariaDB
- One combined `.sql` per input file; batch-convert a whole folder in one run
- Idempotent `CREATE TABLE` (skipped if the table already exists) plus the data, always emitted
- Streaming export: constant memory regardless of table size
- Handles encrypted and legacy (CE 2.0-3.5) databases

## Usage

Double-click `SdfConverter.exe` for interactive prompts, or use the command line:

```
SdfConverter.exe -f <file|folder> [options]

  -f, --file      .sdf file or folder to scan (default: the exe's folder)
  -t, --table     table name(s) to export; repeatable (default: all tables)
  -o, --output    dialect: sqlite (default), postgres, mssql, mysql, mariadb
      --verbose   show detailed progress
      --upgrade   upgrade older SQL CE format to 4.0 (creates .sdf.backup)
  -p, --password  password for encrypted SDF files
```

### Examples

```bash
# All tables of one file to SQLite (default), output beside the input
SdfConverter.exe -f data.sdf

# Specific tables to PostgreSQL
SdfConverter.exe -f data.sdf -t CHECKINOUT -t USERINFO -o postgres

# Convert every .sdf in a folder to MySQL
SdfConverter.exe -f C:\exports -o mysql

# Legacy or encrypted database
SdfConverter.exe -f old.sdf --upgrade
SdfConverter.exe -f enc.sdf -p "secret123"
```

## Output

One `{sdfname}.sql` beside each input file, holding every selected table as batched
INSERTs. Identifier quoting, boolean, and binary literals are rendered for the chosen
dialect (example shown for `postgres`):

```sql
-- Generated by SdfConverter
-- Source: data.sdf
-- Table: 2 tables
-- Records: 45,730
-- Generated: 2024-01-15T10:30:00+07:00

-- Table: CHECKINOUT (45,230 rows)
INSERT INTO "public"."CHECKINOUT" ("USERID", "CHECKTIME", "VERIFYCODE")
VALUES
  (123, '2024-01-15 08:30:00', 1),
  ...;
```

## Build

```bash
dotnet build                 # development
dotnet publish -c Release    # single .exe (~2.4 MB)
```

Output: `bin/Release/net48/publish/SdfConverter.exe`. Requires Windows + .NET Framework 4.8 (or use a self-contained build).
